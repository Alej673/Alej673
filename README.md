### 🚀 Proyectos Destacados

#### 1. [Sistema ERP & Cotizador BTO (Taller de Bastones)](https://github.com/Alej673/sistema-bastones)
Aplicativo web integral bajo el modelo *Built-to-Order*. Aísla la lógica interna de costos del catálogo público usando un doble perímetro de seguridad.
* **Técnicas:** Patrón MVC, Transacciones ACID, Arquitectura MRP, JavaScript Asíncrono.
* **Stack:** PHP, Laravel, MySQL, JS, Bootstrap.

#### 2. [L-IA: Asistente Híbrido (Local/Nube)](https://github.com/Alej673/L-IA)
Asistente personal con un enrutador inteligente que balancea el procesamiento entre la nube y el hardware local (GPU RTX 4050) evaluando tokens e intenciones.
* **Técnicas:** Context Stacking (RAG), Hot-Swap de modelos, Tool Manager (Cortafuegos), NLP.
* **Stack:** Python, Ollama, APIs de LLMs, Tkinter.

#### 3. [Demo UE5: IA Táctica y Shooter](https://github.com/Alej673/MyProject1)
Simulación táctica que aísla las lógicas base de la estética visual. El núcleo de percepción sensorial (cono de visión y oído) alimenta un Behavior Tree modular.
* **Técnicas:** POO, SOLID, Físicas Chaos (Ragdolls paramétricos), Anim Sway.
* **Stack:** C++, Unreal Engine 5, Blueprints.
