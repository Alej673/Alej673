### 🚀 Proyectos destacados

#### 1. [Sistema ERP & Cotizador BTO (Taller de Bastones)](https://github.com/Alej673/sistema-bastones)
Aplicativo web integral bajo el modelo *Built-to-Order*, con un motor de cotización JavaScript propio y un doble perímetro de seguridad que aísla la lógica interna de costos del catálogo público.
* **Técnicas:** Patrón MVC, transacciones ACID, roles y middleware (admin/super_admin), motor de cotización con reglas de negocio centralizadas, reportes PDF con DomPDF.
* **Stack:** PHP, Laravel, MySQL, JavaScript, Bootstrap 5.

#### 2. [L-IA: Asistente Híbrido (Local/Nube)](https://github.com/Alej673/L-IA)
Asistente personal con un enrutador inteligente que balancea el procesamiento entre la nube y el hardware local (GPU RTX 4050) evaluando tokens e intenciones.
* **Técnicas:** Memoria vectorial RAG (ChromaDB), Hot-Swap de modelos, Tool Manager (cortafuegos de permisos), voz híbrida STT/TTS.
* **Stack:** Python, Ollama, Gemini API, Tkinter.

#### 3. [Demo UE5: IA Táctica y Shooter](https://github.com/Alej673/MyProject1)
Simulación táctica que aísla las lógicas base de la estética visual. El núcleo de percepción sensorial (cono de visión y oído) alimenta un Behavior Tree modular.
* **Técnicas:** POO, SOLID, físicas Chaos (ragdolls paramétricos con optimización de Rigid Body Sleep), balística hitscan con cobertura procedural.
* **Stack:** C++, Unreal Engine 5, Blueprints.
